🩸 **Blood Donation Management System**

I built a full-stack web application designed to help connect blood donors with people who need blood.

Users can create donor profiles, search available donors by blood group and city, and submit and track blood requests. Staff can review requests and update their status, while administrators have access to management tools for users, donors, and requests.

**Key features**
- Donor registration and profile management
- Donor search by blood group and city
- Blood request submission and tracking
- Staff and admin workflows with role-based access
- Authentication using JWT and password hashing

**Tech stack:** React, Vite, Node.js, Express, MongoDB, and Mongoose.

This project gave me practical experience building a full-stack application, designing REST APIs, and implementing authentication and role-based access control.
